# Roadmap

## Phase 1 — safe MVP
- [x] Read explicitly configured RSS/Atom feeds.
- [x] Rank listings for text, image and short-content tasks.
- [x] Generate a first-contact draft.
- [x] Export results to CSV.
- [ ] Add and test permitted feed sources.

## Phase 2 — quality
- [ ] Add duplicate detection and date filtering.
- [ ] Add configurable minimum price and preferred task types.
- [ ] Add a checklist for estimating time, scope and risks.
- [ ] Add tests and logging.

## Phase 3 — optional AI assistance
- [ ] Add an optional provider interface for rewriting drafts and preparing deliverables.
- [ ] Keep API credentials local and out of Git.
- [ ] Require human review before any external submission.

## Explicitly out of scope for unattended automation
- Auto-applying to jobs or sending messages without review.
- Circumventing platform restrictions, CAPTCHAs or rate limits.
- Handling client funds, payment credentials or identity documents.
